# @design-eg/cli

```bash
npx @design-eg/cli init          # tokens + Tailwind bridge + cn() helper
npx @design-eg/cli add button    # copy components you own into components/ui
```

Components come from a shadcn-compatible registry, so the same items also work with `npx shadcn add <url>`.

Options: `--yes`, `--overwrite`, `--cwd <dir>`, `--registry <url|folder>`, `--no-install`.
