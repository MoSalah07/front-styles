# Contributing

By taking part you agree to the [Code of Conduct](./CODE_OF_CONDUCT.md).
[AGENTS.md](./AGENTS.md) is the full authoring contract — read it before writing
a component. This page is the short version plus the process around it.

## Setup

```bash
pnpm install
pnpm build
pnpm dev
```

Node 20.9+ and pnpm 9. `pnpm build` must run before `pnpm dev` the first time:
the docs site reads the generated registry.

## Adding a component

1. Create `packages/ui/src/components/<name>.tsx`. Kebab-case file, PascalCase
   export, a file-level doc comment that reads as a sentence — it is published
   as the component's registry description.
2. Add `packages/ui/src/components/<name>.test.tsx` covering render, the
   accessible name, and the main interaction.
3. Add a live example at `apps/docs/content/examples/<name>.tsx` and register it
   in that folder's `index.ts`, so the docs page for the item has something to
   render.
4. Run `pnpm changeset` and pick `minor`.

**Do not edit `packages/ui/src/index.ts`.** It is generated by
`scripts/gen-barrel.mjs` on every build; a hand-written export is overwritten
and causes conflicts. The registry picks new files up automatically too, so no
registry edit is needed.

A block goes in `src/blocks/`, a whole page in `src/templates/`, a hook in
`src/hooks/` — same steps.

## Rules that CI enforces

- **No raw colours.** No hex, `rgb()` or `hsl()` in a component. Use a semantic token.
- **No literal z-index.** Use the `--z-*` scale.
- **Logical properties only.** `ms-*`/`me-*`, not `ml-*`/`mr-*`. `start-*`/`end-*`, not `left-*`/`right-*`.
- **Every interactive element has an accessible name**, and every focusable element has a visible focus ring.
- **Components take `className`** and merge it through `cn()` so consumers can override.
- **Radix first.** If a primitive exists for the behaviour, wrap it rather than rebuilding it.
- **No new npm dependency.** Write it by hand, or open an issue first.

## Adding a brand

Create `packages/tokens/brands/<name>.brand.json` with a seed colour, then run
`pnpm --filter @design-eg/tokens build`. The build prints a contrast report per
brand and fails on an AA violation. Fix it by overriding the offending token in
the brand's `overrides` block rather than by lowering the threshold.

## Before you open a pull request

```bash
pnpm build
pnpm test
pnpm typecheck
pnpm lint
pnpm format
```

Show the change in light, dark, LTR and RTL — the pull request template asks for
all four, because a single light-mode screenshot hides most of what breaks here.

## Removing or renaming anything

Read [VERSIONING.md](./VERSIONING.md) first. Nothing public is removed without a
deprecation that shipped in an earlier release, and removals happen only in a
major. That includes `data-slot` attributes and semantic token names.

## Commits and releases

Conventional commits. Every change to a published package needs a changeset.
Merging the generated "Version Packages" pull request publishes to npm and
writes each package's changelog.
